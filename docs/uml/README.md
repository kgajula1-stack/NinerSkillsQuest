# UML planning files

The PlantUML source files in this directory describe a provisional Sprint 2
data model and persistence flow based only on the current Sprint 1 issues.

They are planning artifacts. The database, ORM, identity model, and API
boundary have not been selected, so the diagrams must be reviewed and updated
before implementation.

Rendered PNG or SVG files are intentionally pending until the team approves
the model and installs or selects a PlantUML rendering workflow.
